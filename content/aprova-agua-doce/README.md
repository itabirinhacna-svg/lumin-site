# Aprova Água Doce — Estrutura das Trilhas BenThec

## Produto principal
Aprova Água Doce

## Modelo pedagógico
Cada trilha será organizada em etapas curtas, no estilo:

1. Entenda
2. Assista
3. Leia
4. Pratique
5. Revise
6. Conclua

- Merendeira

- Operador de Máquinas

### Saúde
- Técnico em Enfermagem

### Magistério
- Conhecimentos Pedagógicos
- Educação Infantil
- Séries Iniciais
- AEE Deficiência Visual
- AEE Deficiência Auditiva

## Regra central
As videoaulas entram como parte da trilha, não como produto principal.

A BenThec entrega organização, acompanhamento, questões, materiais, revisão e direção.
